Ton agent planifie ton fractionné, il apparaît sur ta montre

Relay transmet tes données Apple Health à l'agent IA que tu fais tourner toi-même, et programme sur ton Apple Watch les séances de course qu'il prépare. Tout est chiffré sur ton iPhone avant de partir.

Télécharger sur l'App Store Installer relay-agent

À qui ça sert

Relay est fait pour toi si tu as un iPhone, une Apple Watch et ton propre agent IA : Hermes, OpenClaw, Claude ou ChatGPT par MCP, ou n'importe quel agent qui sait lancer une commande. Ton agent coache, Relay transporte.

Trois étapes

  1. Installer. Installe l'app Relay sur ton iPhone et autorise la lecture de Santé. Côté agent, installe le client relay-agent.
  2. Relier. Lance relay-agent relier : il affiche une session de huit caractères. Saisis-la dans l'app, écran « Relier un agent ». L'app et l'agent affichent le même code à six chiffres : tu vérifies et tu confirmes.
  3. Recevoir les séances. Ton agent lit tes données et planifie une séance : échauffement, blocs d'effort et de récupération, allures cibles, retour au calme. L'app la programme dans l'app Exercice de ta montre, qui l'affiche le jour prévu.

Pas de compte, pas d'email, pas de mot de passe. Si l'agent n'a pas d'écran pour comparer un code, la phrase d'appairage de l'app sert de secours.

Ce que ton agent reçoit

  • Activité : pas, énergie active et au repos, minutes d'exercice.
  • Repas : énergie, protéines, glucides, lipides, eau.
  • Corps : poids, taille.
  • Sommeil par phase, fréquence cardiaque au repos, variabilité cardiaque (VFC).
  • Séances, avec la fréquence cardiaque minute par minute et le tracé GPS pour la course, la marche, la randonnée et le vélo.

Pour chaque type de donnée, l'agent connaît l'heure du dernier échantillon et celle de la dernière synchro : il sait si ses chiffres sont frais. Il peut aussi demander à l'iPhone une synchro immédiate, par une notification silencieuse, quand l'iPhone est déverrouillé.

Le chiffrement, simplement

À la première ouverture, l'app tire une clé de chiffrement de 256 bits. Cette clé reste dans le trousseau de ton iPhone et n'est jamais envoyée au relais. L'app chiffre chaque lot de données avec AES-256-GCM, puis le dépose sur le relais. Seul ton agent, à qui tu as transmis la clé pendant l'appairage, peut le déchiffrer.

Le relais ne voit que des données techniques : un identifiant de compte tiré au hasard, le type et le mois de chaque lot, sa taille, ses dates de dépôt, le jeton de notification de l'iPhone et la date de fin d'abonnement. Il ne voit aucune valeur de santé. L'éditeur non plus.

Le code du relais est public (relay-serveur, licence AGPL-3.0), comme celui du client (relay-agent, licence MIT). Le relais tourne sur un serveur OVHcloud en France. Tu peux aussi héberger le tien et saisir son adresse dans les réglages de l'app.

Installer relay-agent

Sur la machine de ton agent (Python 3) :

pipx install relay-agent      # ou : uv tool install relay-agent
relay-agent relier

Ensuite, selon ton agent :

UsageCommande
Fichiers lus par l'agentrelay-agent sync --dest ~/relay
Résumé santé datérelay-agent resume --dest ~/relay
Planifier une séancerelay-agent seance ajouter …
Serveur MCP (Claude, ChatGPT, Cursor)relay-agent mcp --dest ~/relay
Agent en bac à sablerelay-agent pont --ecoute 172.17.0.1:8771 --dest …

Le pont tourne sur l'hôte avec la phrase : le conteneur de l'agent n'a aucun secret et n'a pas besoin d'accès à Internet. Le détail de chaque commande est dans le README de relay-agent.

Relay Agent : 4,99 € par mois ou 29,99 € par an Les séances envoyées sur la montre et le rafraîchissement à la demande. 14 jours d'essai, résiliable à tout moment dans les réglages Apple.

L'abonnement porte sur le relais hébergé par l'éditeur. Un relais que tu héberges toi-même avec RELAY_GRATUIT=1 ne demande aucun abonnement.

Configuration requise

Un iPhone sous iOS 18 ou plus récent. Une Apple Watch pour les séances. Un agent qui peut lancer une commande ou parler MCP.

Support

Écris à support@relay-agent.app, réponse sous 48 heures. Avant, jette un œil aux problèmes connus : le premier concerne les séances qui n'arrivent pas sur la montre.
